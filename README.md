# Voice AI Assistant

A voice-enabled AI assistant that listens to user speech, processes the request using a Large Language Model (LLM), and returns a spoken response.

This project demonstrates how speech recognition, natural language processing, and generative AI can be combined to build conversational voice applications.

---

## Overview

The Voice AI Assistant allows users to interact with an AI system using voice commands. The assistant converts spoken language into text, processes the request using an AI model, and generates a spoken response.

This project demonstrates how modern AI technologies can be integrated to build voice-based conversational systems.

---

## Features

- Voice input using speech recognition
- AI-powered responses using Large Language Models (LLMs)
- Text-to-speech output
- Real-time conversational interaction
- Web-based interface

Navigate to the project directory:

cd voice-ai-assistant

Install dependencies:

pip install -r requirements.txt

Run the application:

python server.py

## How It Works

The user speaks into the microphone.

Speech recognition converts voice into text.

The AI model processes the text input.

A response is generated by the language model.

The response is converted into speech and returned to the user.
